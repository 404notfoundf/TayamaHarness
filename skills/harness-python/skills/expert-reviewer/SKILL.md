# 专家评审技能（expert-reviewer）— Python 版

> **流水线阶段**: ④ 第四步
> **出口门禁**: 0 个 🔴 严重问题

### 核心规则（一句话摘要）

> **不手下留情。逐项审查 change.md 完整性、架构、编码、安全、测试、流程合规。0 个 🔴 才放行。**

---

## 1. 审查维度与清单

### 维度 1: 功能完整性（对照 change.md）
- [ ] 实现了 **所有** AC？
- [ ] 处理了 **所有** 边界情况？

### 维度 2: 架构合规（对照 工程结构.md）
- [ ] 依赖方向正确（router → handler → service → model）？
- [ ] 新架构决策是否补了 ADR？

### 维度 3: 编码规范（对照 编码规范.md）
- [ ] 命名、docstring 合规？
- [ ] 无硬编码密钥 / 魔法值？
- [ ] LLM/外部调用有超时+重试+限频+降级？
- [ ] 异常处理完整？

### 维度 4: 代码质量
- [ ] 函数 ≤50 行 / 文件 ≤800 行 / 圈复杂度 ≤10？
- [ ] 无未使用 import/变量？
- [ ] 无重复代码块？

### 维度 5: 安全
- [ ] 外部输入已校验？
- [ ] 日志无敏感信息？
- [ ] 无 `eval()` / `pickle.loads` 不可信数据？

### 维度 6: 测试质量
- [ ] 覆盖所有 AC 与边界？
- [ ] 测了降级逻辑？
- [ ] 核心覆盖率 ≥80%？

```markdown

## 🔴 严重问题
### 1. <标题>
- 文件: `<路径>:<行号>`
- 问题: <描述>
- 违反: <规范条目>
- 修复建议: <可操作方案>

## 🟡 建议改进
### 1. <标题>

## 🟢 通过项
- [x] 功能完整性 …

## 结论
<一句话结论>
```
