# 编码规范

> **作用域**: 本项目全模块 PHP 代码标准与约定。
> **基线**: PSR-12 + PHPStan level 8 + 全量 strict_types。
> **状态**: 强制 · 由 `php-cs-fixer` + `phpstan` 机械化检查

---

## 1. 命名约定

| 元素 | 规则 | 示例 |
|------|------|------|
| 类/接口/trait | PascalCase | `RoutePlanningService` |
| 方法 | camelCase | `calculateTotalCost()` |
| 属性/变量 | camelCase | `$maxCallDepth` |
| 常量 | SCREAMING_SNAKE_CASE | `MAX_CALL_DEPTH` |
| 文件 | 类名一致（PSR-4） | `BudgetService.php` |
| 测试方法 | camelCase 描述性 | `testCalculateTotalCost()` |
| 命名空间 | PascalCase 区段 | `App\Services\Budget` |

- 禁止拼音与英文混用、禁止无意义缩写（`$a1`、`$tmp2`）。
- 禁止魔法值：所有字面量定义为 `const` 或枚举。

---

## 2. 注释与文档

- **所有 `public` 类与方法必须有 doc 注释**（`@param` / `@return` / `@throws`）
- 复杂逻辑用行内注释解释**为什么**，而非**做什么**
- `TODO` / `FIXME` 必须转化为 `.harness/changes/` 中的任务条目
- 契约（入参/出参）优先用 PHP 原生类型声明，doc 注释补充

```php
/**
 * 估算给定行程的总费用，按交通/住宿/餐饮/门票四类拆分。
 * 数据缺失时返回保守上界估算。
 *
 * @param TripPlan $plan 行程计划
 * @return CostBreakdown
 * @throws DomainException 当 plan 为空行程时
 */
public function estimate(TripPlan $plan): CostBreakdown
{
    // ...
}
```

### 2.1 import 规范
- 用 `use` 导入，禁止 FQCN 裸写（长度或冲突除外）
- 导入顺序：类、接口、trait 分组；`php-cs-fixer` 自动整理
- 禁止 `use` 未使用的类（phpstan 会报）

### 2.2 日志级别约定
| 级别 | 用途 |
|------|------|
| Debug | 开发调试细节 |
| Info | 关键流程节点 |
| Warning | 降级、重试、限频命中 |
| Error | 需人工介入的失败 |

结构化日志（PSR-3 兼容 logger），含 `timestamp / level / trace_id / message / context`。

## 3. 错误处理

| 规则 | 说明 |
|------|------|
| 不吞错误 | 禁止 `catch (\Exception) {}` 空吞；至少要 log + 降级 |
| 错误分层 | 业务错误抛 `AppException` 子类（含错误码），禁止裸 `throw new \Exception` |
| 返回语义 | 正常/失败用异常或 Result 型；禁止用 `null`/`false` 语义混淆 |
| 错误信息 | 包含上下文，但**禁止泄露密钥/隐私** |

```php
// ❌ 禁止（业务逻辑中吞错）
try {
    $resp = $client->call($req);
} catch (\Exception $e) {
    return null;
}

// ✅ 正确（业务逻辑中降级+记录）
try {
    $resp = $client->call($req);
} catch (ExternalServiceException $e) {
    $this->logger->warning('map api timeout, fallback', ['trace_id' => $ctx->traceId]);
    return $this->offlineEstimate($plan);
}
```

## 4. LLM / 外部调用约束（强制）

每一次 LLM 或外部 API 调用必须具备：

| 维度 | 要求 |
|------|------|
| 超时 | 30s（框架 HTTP client timeout / Guzzle timeout） |
| 重试 | 3 次，指数退避（1s / 2s / 4s） |
| 限频 | 按业务场景配置 |
| 降级 | 必须有默认值/缓存/离线估算，禁止裸抛到用户 |

### 4.1 统一外部调用治理
- 外部调用能力必须尽量收敛到统一封装层，禁止每个模块各自散写一套超时/重试/限频/降级。
- 同一外部依赖在项目内应只有一套主治理策略。

## 5. 类型安全与防御式编程

- 文件首行 `declare(strict_types=1);`（全量强制）
- `public` 方法入参做范围校验（抛 `InvalidArgumentException` 子类）
- 返回值优先强类型；可选值用 `?Type` 或显式 null，禁止用哨兵值（`-1`、"not found"）
- 禁止 `@var` 掩盖类型问题；用 PHPDoc + phpstan 保持类型严谨
- 数组元素类型用 `@param list<Foo>` 标注；优先集合类/Collection

---

## 6. 并发与长任务（Swoole / Workerman / 队列）

- 共享状态走 Redis / 数据库原子操作，禁止进程内全局可变状态承载业务数据
- 长连接（Swoole/Workerman worker）必须管理连接池与超时，禁止连接泄露
- 队列任务幂等：任务设计为可重复执行不产生副作用
- 限制并发信号量（Redis SETNX / semaphore），禁止无界并发

---

## 7. 安全红线

| 红线 | 规则 |
|------|------|
| 密钥 | API Key/Token/密码 → 环境变量 或 配置中心，**禁止硬编码** |
| 日志 | 禁止打印 Token、密码、用户隐私 |
| 输入校验 | 所有外部输入（请求/表单/上传/CLI 参数）必须校验后使用 |
| SQL 注入 | 禁止字符串拼接 SQL，一律参数绑定 / Query Builder / ORM |
| XSS | 输出必须转义（`e()` / twig autoescape），禁止 `$_GET/$_POST` 裸插模板 |
| 反序列化 | 禁止对不可信输入 `unserialize()` |
| 依赖 | 上线前 `composer audit` 0 高危漏洞 |

## 8. 代码质量量化指标

| 指标 | 阈值 | 守护 |
|------|------|------|
| 文件长度 | ≤ 500 行 | phpstan / 人工 |
| 方法长度 | ≤ 50 行 | phpstan / 人工 |
| 圈复杂度 | ≤ 10 | phpstan (cyclomatic) |
| 核心逻辑覆盖率 | ≥ 80% | phpunit --coverage (Xdebug/PCOV) |
| 静态分析 | phpstan level 8 · 0 error | phpstan |
| 格式 | PSR-12 | php-cs-fixer |
| 类型 | strict_types=1 | phpstan / psalm |
| 依赖漏洞 | 0 高危 | composer audit |

## 9. 测试优先编码约定

- 核心业务逻辑、业务规则判断、降级策略默认采用测试先行。
- 每条 AC 应有对应测试映射；每条关键降级路径应有专门测试。
- 测试优先验证**行为与结果**，而不是实现细节。
- PHPUnit 组织：`tests/Unit` + `tests/Integration`；外部依赖用 Mockery / 框架测试替身。

## 11. 简单优先（YAGNI）

- 能用简单方案就不用复杂方案。
- 不为"未来可能的需求"写代码。
- 不引入大型第三方包只为一个小功能。
- 不提前做抽象类/设计模式（Speculative Generality）。
## 12. 单元测试示例（unit-test-write 引用）

```php
final class BudgetServiceTest extends TestCase
{
    public function testCheckShouldTriggerHitlWhenBudgetOverrunExceeds15Percent(): void
    {
        $plan = $this->planWithCost(11500);
        $result = (new BudgetService())->check($plan);
        self::assertTrue($result->requiresHumanIntervention);

    public function testPlanShouldReturnFallbackWhenMapApiTimeout(): void
    {
        $mockClient = Mockery::mock(MapClient::class);
        $mockClient->shouldReceive('distance')->once()

        $svc = new RouteService($mockClient);
        $result = $svc->plan($req);
        self::assertTrue($result->isFallback);
    }
}
```
